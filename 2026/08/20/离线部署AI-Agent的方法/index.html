离线部署AI_Agent的方法

发表于 2026-08-20 更新于 2026-09-18 阅读次数：

最近想离线部署一套AI编程工具，以提高生产力。首先研究离线部署LLM的方法，再研究离线部署AI Agent的方法。

Pi 离线安装

开源的AI Agent有很多，这里使用 Pi agent，因为该AI代理具备持久记忆和自我审查能力，支持完全离线运行，可在Ollama等本地模型上使用，具备长期记忆和自主迭代能力。

安装过程1

  • 安装 NVM nodejs多版本管理工具，从官网下载 NVM 安装 NVM。

  • 使用 nvm 安装最新的 nodejs LTS 版本

  • 安装 npm-bundle 用于打包 pi agent
  • 安装 Pi agent
  • 打包 npm 包

因为打包失败，无法离线安装，暂时放弃此安装方式。

安装过程2

  • 从github下载 pi，即 pi-windows-x64.zip
  • 解压 pi-windows-x64.zip ，并将解压目录添加到 PATH 环境变量

使用方法

  • 运行模式：默认进入交互模式，也支持 -p（打印后退出）或 –mode json/rpc。
  • 内建工具：包含 read（读文件）、write（写文件）、edit（改文件）、bash（跑命令）。
  • 常用交互命令：
    • /model：切换 AI 模型。
    • /settings：调整思考级别（Thinking）和主题。
    • /tree / /fork：浏览会话树、分支管理。
    • /compact：手动压缩上下文。
