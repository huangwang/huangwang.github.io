大模型接入扩展

  • pi-cn-free-model-providers

让 pi（AI 编码助手 CLI）面向中国大陆用户，通过原生通道接入多个免费/低成本模型供应商，包括 OpenCode Zen、SenseNova、SiliconFlow、ModelScope、NVIDIA NIM、AMD Radeon Cloud、Cloudflare 和 Agnes AI。各平台政策可能变化，模型会自动进行实时目录校验。

办公领域

  • pi-subagents

办公多任务拆分核心。把「汇总多份文档 + 写 PPT 大纲 + 整理待办」拆成多个子 Agent 并行处理，适合批量材料、报告撰写。

  • rpiv-todo（@juicesharp/rpiv-todo）

持久化待办清单，会话压缩、重启后任务不丢失。周报、项目跟进、多阶段公文任务必备，支持 /todos 查看任务面板Pi

  • pi-web-access

网页检索、URL 抓取、PDF 解析一体。阅读合同、政策文件、参考资料；自带 OCR，支持扫描版文档提取文字。办公文档处理头号扩展。

  • @gotgenes/pi-permission-system（bash-guard）

权限防护扩展。对删除、覆盖文件、批量修改文档等高风险操作弹窗确认，防止误删合同、报表，办公环境安全底线。

开发领域

  • pi-lens

核心开发扩展，接入 LSP、linters、类型检查、代码静态扫描；每次修改代码自动做语法 / 类型校验，让 Agent 写完代码立刻自检，减少低级 bug，C++/TS/Python 都适用Pi

  • pi-hashline-edit-pro

增强文件编辑工具，基于行哈希定位修改，避免模糊匹配改错代码；支持跨会话撤销，多文件批量修改稳定性大幅提升Pi

  • pi-code

一站式代码增强包，兼容 Claude Code 配置，内置任务清单、检查点、会话记忆、网页检索、子代理能力，开箱即用的完整编码工作流
